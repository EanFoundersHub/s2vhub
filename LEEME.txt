Versión ajustada

Cambios incluidos:
- Estructura limpia para GitHub Pages.
- Partículas reactivas al movimiento del cursor restauradas y reforzadas.
- Video pitch, evidencias y Anexo 1 ahora se abren en un visor modal dentro del sitio.
- Los enlaces dejan de abrirse automáticamente en una nueva pestaña.
- Barras de contexto "Filtrando por" e "Iniciativas en la selección" quedan sticky en Radiografía y Mapa por componentes.
- Vista de detalle más ordenada, con encabezado sticky para mantener visible la iniciativa seleccionada.

Para GitHub Pages:
1. Descomprimir el ZIP.
2. Entrar a la carpeta Selection-Hub.
3. Subir el contenido interno a la raíz del repositorio.
4. Configurar Pages: Deploy from branch > main > /root.

Nota:
Algunos recursos de Google Drive, OneDrive o SharePoint pueden bloquear la vista embebida por permisos del proveedor. En esos casos el modal conserva el enlace original como respaldo.
