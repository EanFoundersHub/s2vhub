SCIENCE2VENTURE SELECTION HUB · V16

CAMBIOS PRINCIPALES
- Se incorporaron cuatro paneles: Panel A, Panel B, Panel C y Panel D.
- Cada panel permite asignar jurados e iniciativas.
- Se puede registrar fecha y hora de inicio y cierre.
- Se puede agregar el enlace de entrevista en Microsoft Teams.
- Coordinación puede:
  · Activar evaluaciones inmediatamente.
  · Usar la apertura automática según el horario.
  · Cerrar las evaluaciones.
- Los jurados pueden consultar previamente toda la información y la rúbrica.
- Los campos de calificación quedan bloqueados fuera de la ventana activa.
- Cada jurado de un panel evalúa los cinco componentes.
- El consolidado de coordinación promedia las calificaciones de los jurados.
- Todas las calificaciones requieren justificación antes del envío.
- Se incorporó el valor de las ventas mensuales en la información financiera/comercial.

CARGA EN GITHUB
1. Descomprime este ZIP.
2. Sube index.html y .nojekyll directamente a la raíz del repositorio.
3. Reemplaza el index.html anterior.
4. Espera el despliegue de GitHub Pages.
5. Abre la URL con ?v=16 y actualiza con Ctrl + F5.

NOTA
La apertura horaria de esta versión se calcula con la hora del navegador.
Cuando se conecte con SharePoint y Power Automate, la validación deberá
ejecutarse también en el backend para que la restricción sea institucional.
